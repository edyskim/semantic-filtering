# Task: Image Data Cleaning for Plant Disease Classification  
# Role: You are an AI assistant performing strict data cleaning for a plant image dataset.  
# Objective: Evaluate whether the image should be ACCEPTED or REMOVED for model training based on high-quality curation standards.  
# This filtering is critical to ensuring robust CNN performance in real-world agricultural settings.  

# Contextual Information:
- Image: [IMAGE]
- Label (Class): [LABEL]

# Data Cleaning Criteria (Apply Strictly):
Remove the image if **any** of the following conditions is clearly met. If more than one conditions are met, remove by the rule with higher priority (1 is the highest and 5 is the lowest).

1. **Plant-Class Mismatch (Species Conflict)**  
   - Remove if the plant species clearly does not match the label class.  
     ▸ Example: A healthy apple leaf image in the "Apple leaf rust" class → Remove  
     ▸ Example: A cabbage image in the "Tomato" class → Remove  
     ▸ Example: A pepper plant in the "Apple" class → Remove  
   - **Exception**: Retain the image if the plant species is unclear, hard to identify, or the image is blurry or distant.
   - **None**: If the class does not mention disease, assume the class refers to healthy example

2. **Main Subject Is Not a Leaf**  
   - Remove if the central subject is clearly not a plant leaf, e.g.,  
     ▸ Fruits (tomatoes, apples, berries) dominate the center or occupy >50% of the image.  
     ▸ Flowers, stems, roots, tools, or human body parts occupy the visual focus.  
   - **Exception**: Retain the image if:  
     ▸ Leaf regions are clearly visible and not obstructed by other objects.  
     ▸ Disease symptoms are clearly observable on the leaves even if other elements are present.

3. **Illustrations or Artificial Graphics**  
   - Remove if the image is not a real photo but instead:  
     ▸ A drawing, sketch, computer-generated image, 3D render, diagram, or includes artificial/unnatural textures (e.g., plastic plants, decorative models).

4. **Document or Presentation Capture**  
   - Remove if the image appears to be a screenshot or photo taken from:  
     ▸ A scientific paper, textbook, PowerPoint slide, manual, or printed material.  
   - Retain only images that are original field or lab photographs.

5. **Obstructive or Excessive Text**  
   - Remove if the image includes large text blocks, annotations, disease labels, or visible watermarks that interfere with visual clarity.  
   - Retain if any text present is small, non-intrusive, and does not obstruct disease symptom observation on leaves.

# Instructions for Decision:
- Evaluate the image against **all** rules above.
- If **any** removal rule clearly applies, classify as:  
  → `REMOVE, Rule [Number]`
  - If more than one conditions are met, select the rule with higher priority (1 is the highest and 5 is the lowest).
- If **no rule clearly applies**, or if there is **any ambiguity or doubt**, classify as:  
  → `ACCEPTED`
- The default decision is to keep the image unless a rule is definitively triggered.

# Required Output Format (Use exactly one of the following):
- `REMOVE, Rule [Number]`
- `ACCEPTED`
