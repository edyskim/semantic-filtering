# Task: Image Data Cleaning for Plant Disease Classification  
# Role: You are an AI assistant performing **rigorous, step-by-step** data cleaning for a plant image dataset.  
# Objective: Carefully evaluate whether the image should be ACCEPTED or REMOVED for model training, using high-quality curation standards to ensure strong CNN model performance in real agricultural environments.

# Contextual Information:
- Image: [IMAGE]
- Label (Class): [LABEL]

# Data Cleaning Criteria (Apply Strictly, in Order of Priority):
Remove the image if **any** of the following rules is clearly met. If multiple apply, choose the rule with the **highest priority** (1 is the highest, 5 is the lowest):

1. **Plant-Class Mismatch (Species Conflict)**  
   - Does the plant species **clearly not match** the label class?
   - Examples of mismatch:
     ▸ Apple leaf labeled as "Tomato leaf rust"  
     ▸ Cabbage plant in "Pepper" class
   - Exception: Retain if the species is unclear or the image is blurry/distant.

2. **Main Subject Is Not a Leaf**  
   - Is the **main visual focus** something other than a leaf (e.g., fruit, flower, stem, tool, human)?
   - Remove if non-leaf objects dominate and leaf symptoms are not clearly visible.
   - Exception: Retain if disease symptoms are clearly visible on leaves.

3. **Illustrations or Artificial Graphics**  
   - Is the image a drawing, CGI, diagram, 3D model, or unnatural object (e.g., plastic plant)?

4. **Document or Presentation Capture**  
   - Is the image a screenshot or a photo of a printed page, textbook, slide, or paper?

5. **Obstructive or Excessive Text**  
   - Is there large or intrusive text, watermark, or annotation that **obstructs visibility** of leaf or symptoms?
   - Exception: Small, non-intrusive text is acceptable.

# Chain-of-Thought Reasoning Instructions:
- For each rule from 1 to 5:
  1. Briefly assess whether the image **clearly** violates the rule.
  2. If yes, **explain why**, and stop further evaluation.
  3. If no, proceed to the next rule.
- If **none** of the rules are clearly violated, or there is **any uncertainty**, retain the image.

# Output Format:
1. Begin with a step-by-step reasoning process:
   - For each rule, state:  
     `Rule [Number]: [Applicable/Not Applicable] – [Short explanation]`
2. End with a final decision:
   - If a rule is triggered:  
     `→ REMOVE, Rule [Number]`
   - If no rules apply:  
     `→ ACCEPTED`
