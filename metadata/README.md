# Public filtering metadata

This directory contains sanitized metadata generated by the semantic filtering experiments. It is intended to support verification of the filtering decisions without redistributing raw images or full model responses.

## Files

| File | Rows | Main columns | Purpose |
|---|---:|---|---|
| `expert_reference_metadata.csv` | 3,000 | `dataset`, `image_id`, `class_name`, `label`, `expert_decision`, `expert_rule` | One row per studied image with the expert reference keep/remove decision and associated rule |
| `vlm_filtering_metadata.csv` | 54,000 | `dataset`, `image_id`, `class_name`, `label`, `model`, `prompt`, `expert_decision`, `expert_rule`, `vlm_decision`, `vlm_rule` | One row per image, model, and prompt condition with VLM decisions aligned to expert reference labels |

`expert_reference_metadata.csv` contains one row per image in the studied PlantDoc and PlantWild subsets:

```text
dataset,image_id,class_name,label,expert_decision,expert_rule
```

`vlm_filtering_metadata.csv` contains one row per image, model, and prompt condition:

```text
dataset,image_id,class_name,label,model,prompt,expert_decision,expert_rule,vlm_decision,vlm_rule
```

The decision columns use:

```text
keep
remove
```

The rule columns use:

```text
none
rule1
rule2
rule3
rule4
rule5
```

`none` indicates that the image was kept. The rule values indicate the semantic filtering rule associated with a removed image.

## Scope

The metadata covers:

- 2 datasets: PlantDoc and PlantWild
- 6 VLM configurations: GPT-4o-mini, GPT-4o, Gemini-2.0-Flash-Lite, Gemini-2.5-Flash, Claude-Sonnet, and Claude-Haiku
- 3 prompt styles: zero-shot, few-shot, and chain-of-thought

The released metadata includes 3,000 expert-reference image rows (1,000 PlantDoc and 2,000 PlantWild) and 54,000 VLM decision rows (3,000 images x 6 models x 3 prompts).

## Excluded fields

The public metadata intentionally excludes:

- raw images
- local image paths
- full VLM natural-language responses
- API logs
- model checkpoints
- private keys or credentials

Raw images should be obtained from the original PlantDoc and PlantWild sources listed in `docs/DATASETS.md`.
